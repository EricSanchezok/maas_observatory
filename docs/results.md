results. A result will be added only after:

1. the experiment has a clean, immutable manifest and completion record;
2. all selected tasks have a recorded outcome or explicit not-run reason;
3. the release bundle passes schema, checksum, and redaction validation;
4. methodological limitations and missing infrastructure are disclosed;
5. the archive and checksum are attached to an immutable GitHub Release.

Published tables will link to the exact run ID, Git commit, benchmark revision,
configuration digest, release archive, and machine-readable metrics.
